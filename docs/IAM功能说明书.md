# IAM 功能说明书（Feature Specification）

> 版本：v1.0 ｜ 日期：2026-08-14
> 依据：AWS IAM / Microsoft Entra ID / Google Cloud IAM / Keycloak / Okta / SailPoint（IGA） / One Identity（PAM） / 阿里云 IDaaS / 腾讯云 IDaaS / 等保 2.0（GB/T 22239-2019）等公开资料整理。

## 三、身份认证（Authentication / AuthN）

### 3.1 基础认证
| 功能 | 说明 | 状态 |
|------|------|------|
| 用户名/密码登录 | 支持账号=用户名/邮箱/手机 | ✅ |
| 验证码登录 | 短信/邮箱验证码免密登录 | 🟡（验证码绑定用，未做登录态） |
| 二维码/扫码登录 | 企业微信/钉钉等扫码 | ⬜ |
| 无密码登录 | Passkey / WebAuthn / 生物识别 | ⬜ |

### 3.2 多因素认证（MFA）
| 功能 | 说明 | 状态 |
|------|------|------|
| TOTP 动态口令 | RFC 6238，兼容 Google Authenticator | ✅ |
| 备用验证码（Recovery Codes） | 设备丢失时应急登录 | ✅ |
| 短信/邮件 OTP | 一次性动态码 | ✅（绑定验证码✅ + 登录 OTP✅：策略开关，TOTP 之外的登录二次认证） |
| FIDO2 / WebAuthn | 安全密钥（YubiKey）、平台生物识别 | ⬜ |
| X.509 证书认证 | 证书方式身份鉴别 | ⬜ |
| 强制 MFA | 策略强制开启，登录强制二次验证 | 🟡（策略字段预留，未做强制） |
| 分步认证（Step-up） | 高敏感操作二次认证/升级认证 | 🟡（敏感操作=改密/解绑，未做通用） |

### 3.3 密码策略与凭证
| 功能 | 说明 | 状态 |
|------|------|------|
| 密码复杂度（长度/字符组合） | 可配置最小长度、字母/数字/特殊字符 | ✅ |
| 弱密码黑名单 | 常见弱口令字典校验 | ✅ |
| 历史密码防重用 | 保留最近 N 次禁止复用 | ✅ |
| 密码有效期/定期更换 | 过期强制改密（等保） | ✅ |
| 首次登录强制改密 | 管理员重置后必须改密 | ✅ |
| 密码加密存储 | bcrypt/argon2 哈希，不存明文 | ✅ |
| 忘记密码/自助重置 | 验证码重置，重置后吊销令牌 | ✅ |
| 密码保险库 | 凭据安全托管（PAM vault） | ✅（雏形：AES-256-GCM 密文存储，受控查看留痕） |

### 3.4 登录安全控制
| 功能 | 说明 | 状态 |
|------|------|------|
| 登录失败锁定 | N 次失败锁定 X 分钟（等保） | ✅ |
| 登录限流 | IP 维度频率限制，防暴力破解 | ✅ |
| 会话超时自动退出 | 空闲超时 / 绝对超时 | ✅（空闲超时，策略可配） |
| 防账号枚举 | 失败统一提示"账号或密码错误" | ✅ |
| 验证码/人机验证（reCAPTCHA） | 注册/登录防机器人 | ⬜ |

## 四、单点登录与联邦（SSO & Federation）

### 4.1 SSO 单点登录
| 功能 | 说明 | 状态 |
|------|------|------|
| 一次登录访问多系统 | 登录一次免密访问所有授权应用 | ✅ |
| 单点登出（SLO） | 登出一个系统全局退出 | ✅ |
| 未登录重定向流程 | 访问应用→跳登录页→回跳原应用（含深层路径） | ✅ |
| open redirect 防护 | 白名单校验回跳地址 | ✅ |
| 跨域 SSO（cookie 隔离） | 支持跨域多应用会话共享 | ✅（应用 A/B 各自维护本地会话，通过标准 OIDC 授权码流程接入 IAM 实现单点登录与统一登出） |

### 4.2 协议与标准
| 功能 | 说明 | 状态 |
|------|------|------|
| OIDC（OpenID Connect） | 现代身份认证协议（JWT ID Token + UserInfo） | ✅（授权码模式：发现/JWKS/authorize/token/userinfo，RS256 签名；关联应用 A/B（员工门户/项目管理）已通过本协议统一接入，未登录自动跳转 IAM 授权，登录一次可免密进入 A、B） |
| OAuth 2.0 | 授权委托框架（access token + scope + 多种 grant） | ✅（grant：authorization_code（OIDC 授权码）+ client_credentials（服务账号）+ refresh_token（轮换换发）；RFC 7009 revoke 令牌吊销；RFC 7662 introspect 令牌检视（含 scope）；发现文档补全端点） |
| SAML 2.0 | 企业级 XML 联邦标准（SP/IdP） | ⬜ |
| CAS | 传统高校/企业 SSO 协议 | ⬜ |
| Kerberos | Windows 域内票据认证桥接 | ⬜ |
| 身份代理（Identity Brokering） | 对接外部 IdP（OIDC/SAML），如 Keycloak/Okta | ⬜ |
| 社交登录 | Google/GitHub/Facebook/微信/QQ 等 | ⬜ |
| 令牌交换（Token Exchange） | 服务间受控令牌转换 | ⬜ |
| CIBA / 设备流（Device Flow） | 无浏览器设备认证 | ⬜ |

## 五、授权管理（Authorization / AuthZ）

### 5.1 模型
| 功能 | 说明 | 状态 |
|------|------|------|
| RBAC 角色权限 | 用户-角色-权限，角色绑定权限 | ✅ |
| 组继承授权 | 用户加入组自动获得组角色 | ✅ |
| 细粒度权限/权限点 | permission 粒度控制 | ✅ |
| ABAC 属性授权 | 基于用户/资源属性（部门、职级等）授权 | ✅（属性模型：用户内置字段 department/status/realm + 扩展 key-value 属性；策略规则 CRUD：资源类型/effect(allow|deny)/优先级/启停/多条件 AND；条件表达式 lhs/op/rhs，op 支持 eq/ne/in/contains/exists/gt/ge/lt/le，lhs 支持 user.*/user.attr.*/resource.*/context.*；决策点 POST /authz/check，deny 优先于 allow，未命中返回 default 由调用方按 RBAC 兜底；管理端页签 + 审计） |
| 策略引擎（PBAC） | 集中策略驱动授权（如 OPA/XACML） | ⬜ |
| 资源级授权/对象级权限 | 针对具体资源/对象的访问控制（AWS 资源策略） | ⬜ |
| 强制访问控制（MAC） | 安全标记 + 强制访问规则（等保四级） | ⬜ |
| 职责分离（SoD） | 互斥角色/权限冲突检测 | ✅（互斥规则配置；用户/组/角色权限分配时拦截冲突） |

### 5.2 权限治理
| 功能 | 说明 | 状态 |
|------|------|------|
| 最小权限原则 | 按需授权，权限收敛 | 🟡（人工，无检测） |
| 权限分离 | 管理/审计/运维权限隔离（等保） | ✅（不同权限点） |
| 越权防护 | 防水平/垂直越权 | 🟡 |
| 会话权限生效 | 权限变更即时/会话内生效 | 🟡 |

## 六、身份治理与合规（IGA）

| 功能 | 说明 | 状态 |
|------|------|------|
| 访问请求与审批流 | 自助申请权限 → 多级审批 → 自动开通 | ✅（用户自助申请角色+原因；审批级数可配（approval_levels，默认1）；不同审批人逐级审批、同人重复审批拦截；全部通过自动赋权，SoD 冲突自动拒绝；管理端"访问审批"页签 + 全链路审计） |
| 访问认证（Access Certification） | 定期让主管确认用户权限是否仍需保留 | ✅（复审活动：按部门/用户范围快照角色分配，逐项保留/撤销（撤销即时回收），截止未审项按策略自动处置（默认撤销），到期惰性自动关闭，全程审计） |
| 角色挖掘（Role Mining） | 从现状自动归纳角色模型 | ✅（基于用户有效权限集做权限共现统计，推荐候选角色（权限组合+覆盖用户+支持度，支持度可配），跳过与已有角色相同的组合；一键落库为正式角色并可分配给覆盖用户；管理端"权限分析"页签） |
| 策略违规检测 | 检测过度授权/权限漂移（privilege creep） | ✅（僵尸持权（久未登录仍持权，天数可配）、敏感权限持有（高风险权限集合可配）、权限聚集（有效权限数超阈值）；输出高危/中危分级与处置建议；全审计） |
| 审计台账（Identity Warehouse） | 全量"谁拥有什么权限"视图 | ✅（用户×角色×权限，含来源标记，CSV 导出） |
| 工作流引擎 | 审批/申诉/升级/通知自动化 | ✅（通用引擎：approval 审批（按角色/用户指定审批人）+ condition 条件分支（eq/in/gt/lt/true/empty）+ action 动作回调；实例/待办/状态机（running/completed/terminated）；可配置开关 workflow_engine_enabled，开启后访问请求走引擎（如两级审批链），关闭保留旧 approval_levels 逻辑；管理端"工作流"页签 + 待办审批 + 全审计） |
| AI 身份治理 | 异常访问模式检测、风险评分（新一代 IGA） | ⬜ |

## 七、特权访问管理（PAM）

| 功能 | 说明 | 状态 |
|------|------|------|
| 特权账号发现与登记 | 管理员/共享账号清点 | ✅（自动发现：持有敏感权限的用户（复用 analytics_sensitive_perms）→ 管理员、活跃服务账号 → 服务、标记 shared 的账号 → 共享，幂等入台账；手动登记 + 风险分级（高/中/低）+ 退管 + 审查标记；可与凭据保险库关联；清单统计（类型/风险/待审查/未关联）；全审计） |
| 凭据保险库（Vault） | 密码托管、动态取用、自动轮换 | 🟡（AES-256 加密托管 + 动态取用（reveal 留痕）+ 权限审计台账；自动轮换未实现） |
| 即时访问（JIT） | 按需临时提权，用完即回收 | ✅（自助申请临时角色（限时，上限 jit_max_minutes）+ 审批（approval:manage）→ 限时生效（expires_at）；到期惰性自动回收，管理端可随时撤销；SoD 预检；全程审计 jit.request/approve/reject/revoke/expire） |
| 会话录制/监控 | 特权会话全程录制与审计 | ⬜ |
| 应急访问（Break-glass） | 紧急通道 + 强认证 + 全程留痕 + 事后审查 | ✅（免审批限时高权限通道：须已开启 TOTP 且动态码强认证（step-up）+ 应急理由；临时授予应急角色（默认含全部权限，可配 breakglass_role_id），限时（breakglass_duration）到期惰性自动回收；用户可自主结束、管理端可强制结束；事后由 breakglass:manage 审查闭环；全程审计 start/denied/end/review） |
| 提权审批 | 提升权限需审批（one-time approval） | ✅（即"即时访问 JIT"：用户申请临时角色（限时）→ 审批人 approval:manage 逐单审批/拒绝，通过后限时生效、到期自动回收，见 7.5） |
| 特权会话 MFA | 提权点强制 MFA / step-up | ✅（应急访问 Break-glass 入口强制 TOTP 动态码强认证（step-up）方可进入特权会话，见 7.6） |
